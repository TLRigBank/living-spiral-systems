# RAF Commercial Shell — interface contract
Sealed 2026-09-15. Four Bots. No Ember. Human is a mode.

The product UI is iMessage-shaped. We do not rebuild it. We use presence, the Bot computer, and one write-target file the way the good fleets do.

## 2. Indigo evidence pane (computer preview)

Indigo does not argue from memory when a Public artifact has a URL.

On CLAIM:
1. Open the artifact URL on the Bot computer.
2. Leave it in **preview** (side panel). Do not narrate the whole page.
3. Verdict is one sentence after GATE: what the page actually says vs what Saffron claimed.
4. Takeover only if the human asks.
5. Warm rows have no URL — skip the browser; judge the permissioned sentence only.

FAIL if Saffron’s “their sentence” is not on the page.

## 3. Pipeline as the write-target

`docs/pipeline-exploring.md` is the page the Bots write to (same pattern as a self-updating site). The thread is not the system of record.

- Saffron appends PASS rows to that file on the shared computer / GitHub path.
- Slate ends every Sweep with: path + row count + QUIET/PASS.
- Sent? stays N until the human marks it after a real send.
- Do not dump pipeline into STATE-LEDGER except one weekly uptake line the human requests.

## 4. Human is a mode

Visible in the transcript, not a hidden admin screen.

- STEER = human must act (send, invoice, create the hold).
- Purple computer / preview = Bot is working; do not hover the whole time.
- Takeover = you drive the computer, then hand it back.
- No routine sends mail or creates calendar events unless the human says `create the hold`.

## 5. Teach after proof, not before

After the first live Sweep that produces a real table (or an honest QUIET), long-press that turn → Teach as Routine only if the four scheduled routines are already created. Do not teach a fifth routine from a sloppy run.
